# README 截图清单

README 里引用的图片都放在这个目录。下面是需要的截图、用途与硬性要求。
**提供原始 PNG 就行**，裁边/缩放/合并我可以处理（也可以你自己处理）。

## 二、技术要求

- **控制台窗口要拉到 ≥ 120 列再截**：脚本的表格是按显示宽度对齐的（中文按双宽计算），
  窗口太窄会折行，表格就花了。
- 字体缩放建议 125%–150%，字更清楚；深色/浅色主题都行，但**多张之间保持一致**。
- 格式 PNG；宽度 ≤ 1600px；单张尽量 ≤ 500KB（GitHub 会自动缩放显示）。
- 只截需要的区域，别把整个桌面、任务栏、其他窗口一起截进来。

## 三、脱敏要求（重要）

截图里**不要出现**：

- 真实用户名，例如 `C:\Users\你的名字` → 用示例路径（如 `D:\JavaDevEnv`）或打码
- 真实密码 / 密钥 / token → 配置里用默认的 `postgres`，或改成示例值
- 内网 IP、公司域名、代理地址、私有仓库地址
- 无关窗口、聊天软件通知、浏览器书签栏
